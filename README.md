# Інтернаціоналізація (i18n) вебдодатків мовою JavaScript

Єдиний вебдодаток, що демонструє роботу багатомовності (локалізації) одразу кількома способами: через чистий JavaScript (`fetch` + JSON), бібліотеку **i18next**, а також містить каталог товарів із модальним вікном вибору мови та збереженням вибору в `localStorage`.

## 📂 Структура проєкту

```text
├── index.html          # Єдина HTML-сторінка з усіма блоками завдань
├── locales/            # Файли перекладів для чистого JS
│   ├── en.json
│   └── uk.json
├── script/
│   └── app.js          # Загальна логіка (fetch, i18next, модальне вікно, каталог)
└── README.md
